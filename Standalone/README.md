# Standalone application

The native MuJoCo application lives in this directory. Use the
[CombatSim documentation](../docs/index.md) for the user guide and
[Building from source](../docs/development/building.md) for developer setup.

The sample fighting arena is `models/CombatRobot500g.xml`. It is also the
default model used by the launcher and command-line diagnostics.
