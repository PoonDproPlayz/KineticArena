# CombatSim

CombatSim is a Windows desktop simulator for small combat robots. It uses
MuJoCo for physics and can import robot assemblies exported from Fusion 360.

## Start here

- [Read the user guide](https://poondproplayz.github.io/KineticArena/)
- [Install and build on Windows](docs/getting-started.md)
- [Import a Fusion 360 robot](docs/configuration/fusion-import.md)
- [Build and code layout](docs/development/building.md)

The current project is the native C++ application in `Standalone/`. It is built
from source; the planned single-file portable release package is not available
yet.
